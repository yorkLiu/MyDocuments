# 水鬼 - 民间妖怪故事动画

## 项目概述
基于中国民间传说改编的妖怪故事动画视频。

## 故事梗概
少女小林在月圆之夜独自来到古镇的石桥上，遇到了一个从水中升起的水鬼。
原来这个水鬼是她失踪二十年的父亲——当年为了救落水的她而溺亡。
水鬼回来不是为了害人，而是为了告别。

## 核心卖点
- **恐怖开场**：水鬼升起的视觉冲击
- **情感反转**：从恐怖到温情的叙事转折
- **亲情内核**：父爱如山，跨越生死
- **系列化**：可做成"中国妖怪图鉴"系列

## 制作工具
- 图片生成：Agnes.ai (agnes-image-2.0-flash)
- 视频合成：FFmpeg (libx264)
- 配音：edge-tts (zh-CN-YunxiNeural) — **逐场景独立配音**
- BGM：FFmpeg lavfi — **逐场景情绪匹配**（12段不同BGM）
- 字幕：文泉驿正黑 (UTF-8) — **已修复乱码**

### 核心修复
- ✅ 零静音填充：先配音→测时长→画面=配音+1.5s
- ✅ 字幕与配音同步：`enable='between(t,0,配音时长)'`
- ✅ BGM贯穿全程：每场景独立BGM + 两两concat拼接
- ✅ 音频时长匹配视频：128.9s音频 = 129.1s视频
- ✅ 配音用apad补齐：配音结束后BGM自然过渡1.5s
- ✅ 修复vibrato:d=1.5越界（改为d=0.8）

### 修复记录
- ✅ 字幕乱码 → 指定文泉驿正黑字体 UTF-8
- ✅ 没有声音 → edge-tts 逐场景生成中文配音（云希男声）
- ✅ 没有BGM → FFmpeg 生成6段情绪BGM（压抑→恐惧→转折→温暖→悲伤→释然）
- ✅ 时长不足 → 从64秒延长到129秒（2分9秒）
- ✅ 声画不同步 → 先配音后定画面，零静音填充
- ✅ BGM缺失 → 逐场景独立BGM + 两两concat拼接
- ✅ 声音断续 → 配音贯穿全程（apad补齐），BGM不间断
