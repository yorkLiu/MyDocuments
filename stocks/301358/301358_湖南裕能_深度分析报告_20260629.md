## 一、基本面分析（核心维度）

### 1.1 公司业务模式和核心竞争力

**湖南裕能**（全称：湖南裕能新能源电池材料股份有限公司）是国内**磷酸铁锂正极材料绝对龙头**，申万行业属"有色金属-金属非金属新材料-电池材料"。

| 维度 | 说明 |
|------|------|
| **主营业务** | 锂离子电池正极材料（磷酸铁锂为主），营收占比97.94% |
| **核心产品** | 磷酸铁锂正极材料（YN-13循环寿命12000次，远超同行） |
| **客户结构** | 宁德时代（第一客户）+比亚迪（第二大靠山），双龙头绑定 |
| **一体化布局** | "磷矿—磷酸铁—正极材料—循环回收"全链条 |
| **磷矿自供** | 贵州黄家坡磷矿（年产120万吨）+打石场磷矿，磷酸铁基本实现自供 |
| **海外布局** | 西班牙锂电正极材料项目（出海先行者） |
| **核心护城河** | 磷矿自供→单吨成本低于行业500-800元；储能场景市占率超41% |

**商业模式特点**：磷酸铁锂行业存在"客供料"（碳酸锂Buy & Sell）模式，营收含大量碳酸锂流转值，因此**毛利率天然偏低**，需重点看净利率和单吨盈利趋势。

**关键判断**：

1. **盈利拐点已确认**：2026Q1净利润13.56亿→**单季已超2025全年12.77亿**，这是本轮周期最核心的信号。毛利率从2024年7.85%跃升至2026Q1的16.16%，**翻倍式改善**主要由磷酸铁锂涨价+磷矿自供降本驱动。

2. **营收高增但含Buy&Sell水分**：2026Q1营收149.65亿（同比+121%），需注意其中包含碳酸锂客供料流转。但毛利率的翻倍改善已证明盈利质量的实质提升。

3. **ROE强劲回升**：从2024年5.2%→2026Q1年化近40%，盈利能力已恢复至健康水平。

4. **经营现金流持续为负**：这是**最大财务隐忧**。每股经营现金流连续多年为负（-1.37元），反映行业重资产属性+下游强议价导致应收高企（应收账款周转天数48.77天，改善中但仍偏高）。

5. **资产负债率改善**：从2022年78.38%降至2026Q1的61.23%，但仍在60%+水平，杠杆不低。

### 1.3 行业地位和市场份额

| 维度 | 现状 |
|------|------|

| **储能场景** | 市占率超41%，绝对统治地位 |
| **国内排名** | 磷酸铁锂出货量连续多年No.1 |

| **行业增速** | 2026年全球磷酸铁锂正极材料出货量预计达525万吨，同比增速可观 |

**行业拐点信号明确**：2025Q4以来，磷酸铁锂行业出现"涨价潮+供给紧平衡"，多家头部企业提前锁单、扩产、甚至安排产线检修控制供给。行业盈利从底部反转，湖南裕能作为龙头弹性最大。

**重大治理事件**：宁德时代作为湖南裕能持股5%以上股东，于2026年5月29日公告减持至5%以下（套现或超20亿），同时宁德时代加速将磷酸铁锂订单向容百科技、万润新能等分散化，**这是当前最核心的治理隐患**。

## 四、风险评估

### 4.1 主要投资风险识别

| 风险等级 | 风险因素 | 影响程度 |
|----------|----------|----------|
| 🔴 **高** | 宁德时代客户分散化+减持 | 利润率+订单量双重冲击 |
| 🔴 **高** | 碳酸锂价格剧烈波动 | Buy&Sell模式下营收和利润双波动 |
| 🟡 **中** | 磷酸铁锂行业扩产过热 | 或再次供过于求，压制毛利率 |
| 🟡 **中** | 经营现金流持续为负 | 资金链安全边际收窄 |
| 🟢 **低** | 海外项目地缘风险 | 西班牙项目尚在早期 |

### 4.2 行业和政策风险

1. **客户集中度+反向博弈**：宁德时代已与容百科技签署6年磷酸铁锂采购协议（2026Q1至2031年），万润新能亦获132万吨大单，**湖南裕能面临核心客户订单被分流的风险**。但比亚迪作为第二大客户可提供一定缓冲。

2. **行业政策**：新能源补贴退坡+储能政策频出，整体利好磷酸铁锂（储能几乎100%使用LFP路线），但需警惕海外关税壁垒。

3. **技术替代风险**：固态电池/磷酸锰铁锂（LMFP）是中长期潜在替代路线。但公司已在LMFP和固态电池领域布局储备。

### 4.3 财务风险和经营风险

| 风险 | 数据支撑 | 评估 |
|------|----------|------|
| **杠杆风险** | 资产负债率61.23% | 中等，重属性行业可接受 |
| **流动性风险** | 流动比率1.29 | 偏低但回升中 |
| **应收风险** | 应收周转48.77天 | 较2024年79天大幅改善 |

| **存货风险** | 存货周转2.87次（Q1） | 季节性因素，关注碳酸锂跌价减值 |

### 4.4 市场风险和流动性风险

- **解禁/减持压力**：宁德时代减持至5%以下是当前最直接的市场压制因素。
- **流动性**：日均成交20亿+，换手率3-4%，流动性充足，不存在流动性枯竭风险。
- **大股东质押**：暂未发现异常质押数据。

## 六、核心结论

**湖南裕能正处于磷酸铁锂行业周期盈利拐点的核心位置。** 2026Q1净利润13.56亿已超2025全年，毛利率翻倍至16.16%，行业涨价+磷矿自供降本的双轮驱动正在兑现。

当前动态PE仅11.63x，在同行中估值最低，存在约30-50%的估值修复空间。但短期面临宁德时代减持+订单分散化+技术面均线空头的三重压制，需要时间消化。

**以积极风险偏好视角**，当前价位是"盈利拐点确认后的估值修复期"，属于"逻辑最硬、价格最软"的布局窗口。策略上建议**分批建仓**，耐心等待Q2数据验证和短期技术面修复。
